# EA Trading Dashboard

MetaTrader Expert Advisor Performance Tracking Dashboard for Home Assistant.

## Installation

1. Add this repository to Home Assistant:
   - Go to **Settings** → **Add-ons** → **Add-on Store**
   - Click **⋮** → **Repositories**
   - Add: `https://github.com/ArrestedOps/ha-ea-dashboard`

2. Install the EA Trading Dashboard add-on
3. Start the add-on
4. Configure your MT4/MT5 Expert Advisors to send webhooks to: `http://homeassistant.local:8099/api/webhook`

## Features

- Real-time MT4/MT5 account tracking
- Live trade monitoring  
- Performance analytics
- Mobile-optimized dashboard
